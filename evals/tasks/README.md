# evals/tasks/

10 tarefas reais, **por projeto**, cujo resultado certo já conheces.

Este é o ativo mais caro de produzir e o único insubstituível da Factory.
Sem ele, cada alteração a uma skill é uma opinião sobre uma opinião.

## Mistura sugerida

| # | Tipo |
| --- | --- |
| 1–3 | feature no fluxo principal do produto |
| 4–5 | bug com causa conhecida |
| 6–7 | alteração de schema |
| 8 | performance |
| 9 | refactor |
| 10 | **a que correu mal** — a sessão que te obrigou a reverter tudo |

A número 10 é a mais valiosa das dez.

## Onde vivem

Num projeto instalado: `evals/tasks/` do próprio projeto.
Aqui ficam só o template e estas instruções — a Factory não tem tarefas próprias.
